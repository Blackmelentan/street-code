Unified Multi-Role Intake

Six distinct customer and civic account types share one unified sign-up pipeline: vehicle owner, collector, fleet operator, garage mechanic, parts vendor, and driver. Each role unlocks tailored features, but all interact with the same underlying vehicle and identity ledger.

Instead of fragmented apps, Street Code is one cohesive operating system with role-based lenses.
